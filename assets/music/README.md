# مكتبة الموسيقى الخلفية (Background Music)

حط هنا ملفات الموسيقى الخلفية (`mp3` أو `wav`) اللي تحب تستخدمها في فيديوهاتك.
سكربت `scripts/mix_audio.py` هيوطّي الموسيقى تلقائياً تحت صوتك (**Auto-Ducking**) ويعمل Fade-in و Fade-out ناعم.

### مصادر مجانية 100% بدون حقوق طبع ونشر (No Copyright):
1. **YouTube Audio Library** (من داخل YouTube Studio — آمنة تماماً لكل المنصات).
2. **Pixabay Music** (`pixabay.com/music` — ابحث عن `lo-fi`, `corporate`, `tech`, `cinematic`).
3. **Mixkit** (`mixkit.co/free-stock-music` — تحميل مباشر مجاني).

> **نصيحة:** سمّي الملفات بأسماء واضحة زي `energetic.mp3` و `lofi-edu.mp3` و `cinematic.mp3` عشان تربط كل تراك بالستايل المناسب في `brand.md`.
